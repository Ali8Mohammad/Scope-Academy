# Scope Academy Website

Vanilla HTML/CSS/JavaScript implementation for the Scope Academy public website.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript (ES Modules)
- Vite for development/build tooling only

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Current implementation
- RTL-ready semantic page structure
- Top information bar
- Responsive navigation
- Hero section based on the supplied Figma values
- Design tokens for brand colors, typography, spacing, buttons and radius
- Placeholder data layer for specialties, trainers and partners
